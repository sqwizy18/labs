### Пример расчета для variant.py (Вариант 1 — Заряд аккумулятора)

**Исходные данные:**

* **Вводимое число:** 15
* **Допустимый диапазон:** от 0 до 100 включительно
* **Категории:** 
  * 0–19: Низкий
  * 20–79: Средний
  * 80–100: Высокий

**Ручной расчет:**

1. **Проверка диапазона:**  
   0 <= 15 <= 100 (Истина) -> Ошибки диапазона нет.

2. **Проверка условий по порядку:**  
   15 <= 19 (Истина) -> Выполняется первая ветвь.

3. **Результат:**  
   Категория: Низкий
