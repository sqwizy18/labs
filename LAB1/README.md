**Исходные данные:**

* **Название заказа:** Канцелярия
* **Имя заказчика:** Иван
* **Позиция 1:** Тетради — 10 шт. по 45.50 руб.
* **Позиция 2:** Ручки — 5 шт. по 25.00 руб.
* **Стоимость доставки:** 150.00 руб.
* **Скидка на товары:** 10%
* **Внесенная сумма:** 1000.00 руб.

**Ручной расчет:**

1. **Стоимость первой позиции (Тетради):**  
   10 * 45.50 = 455.00 руб.

2. **Стоимость второй позиции (Ручки):**  
   5 * 25.00 = 125.00 руб.

3. **Общее количество товаров:**  
   10 + 5 = 15 шт.

4. **Стоимость товаров без скидки и доставки:**  
   455.00 + 125.00 = 580.00 руб.

5. **Размер скидки (10%):**  
   580.00 * 0.10 = 58.00 руб.

6. **Стоимость товаров со скидкой:**  
   580.00 - 58.00 = 522.00 руб.

7. **Общая сумма с доставкой:**  
   522.00 + 150.00 = 672.00 руб.

8. **Сдача:**  
   1000.00 - 672.00 = 328.00 руб.
